# CareerAI 

 AI-powered career intelligence platform — from skill gaps to placement success, all in one workspace.

🚀 Overview

CareerAI is a web-based platform that helps engineering students and job seekers navigate their career journey using AI-driven insights. It brings job matching, skill analysis, interview prep, and placement tracking into a single, unified workspace.

## ✨ Features

- **Job Match** — AI-driven job and role recommendations based on your profile and skillset
- **Skill Gap Analysis** — Identifies missing skills for target roles and suggests learning paths
- **Career Intelligence (SWOT)** — Personalized Strengths, Weaknesses, Opportunities, and Threats analysis
- **Mock Interview** — AI-simulated interview practice with real-time feedback
- **Placement Drives** — Track and manage placement drive applications and readiness
- **Assessments** — Skill and knowledge tests to benchmark job readiness *(in progress)*

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Backend:** Supabase (PostgreSQL, Auth, Edge Functions)
- **Styling:** Tailwind CSS
- **Package Manager:** Bun

## 📦 Getting Started

### Prerequisites
- Node.js (v18+) or Bun
- Supabase account (for backend setup)

### Installation

```bash
git clone https://github.com/vaishnavithamma/careerai.git
cd careerai
bun install
```
